# 🧮 Advanced Smart Calculator

A modern **Smart Calculator** built using **HTML, CSS, and JavaScript**. This project combines multiple useful tools into one responsive web application.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🟰 Percentage
- √ Square Root
- x² Square
- 🎂 Age Calculator
- 📏 Height Converter
- ⚖️ Weight Converter
- 💪 BMI Calculator
- 🌙 Dark Mode
- 📜 Calculation History
- 📱 Fully Responsive Design
- ⌨️ Keyboard Support

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

1. Clone this repository

```bash
git clone https://github.com/YOUR-USERNAME/advanced-smart-calculator.git
```

2. Open the project folder.

3. Open **index.html** in your browser.
